О проекте

Сайт считает, кто ещё может стать чемпионом Формулы-1 2026: по очкам, оставшимся этапам и шкале очков, которую можно менять. Вероятность титула оценивается симуляцией 20 000 сезонов.

У каждого пилота есть карточка с фото. Нажмите на фото, чтобы посмотреть данные сезона и выбрать любой год с 1950-го. На странице «Сезоны» собраны чемпионы всех лет и итоговые таблицы пилотов.

На чём сделан

HTML, CSS и JavaScript без библиотек. Фото и описания пилотов берутся из Википедии, архивные данные сезонов — из открытого API Jolpica (Ergast). Очки 2026 года по умолчанию взяты с crash.net после Гран-при Сингапура.
